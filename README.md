🗳️ 會議簽到與投票系統 (Meeting Voting App)

這是一個基於 Flutter 開發的會議管理 App，專為期中專案設計。
具備完整的身分權限管理、即時簽到儀表板以及動態投票系統。

✨ 核心功能

1. 👥 會議身分與權限管理

多重身分支援：區分「主席」、「紀錄」、「出席 (有投票權)」、「列席 (無投票權)」。

小明條款 (遲到邏輯)：

即使是出席委員，若遲到未簽到，則無投票權。

需簽到後，由主席執行「清點人數」，才會即時賦予投票權。

2. 📊 簽到儀表板

即時統計：可視化顯示各身分的「已到/應到」人數。

詳細名單：下方列表即時顯示每位與會者的簽到狀態與投票資格。

3. 🗳️ 動態投票系統

靈活選項：主席可動態新增/刪除投票選項 (不限數量)。

即時開票：支援記名/不記名投票，並即時顯示長條圖結果。

防呆機制：僅有權限者可投票，且不可重複投票。

4. 📂 資料匯入與匯出

CSV 匯入：支援從手機儲存空間匯入人員名單 CSV 檔。

範例下載：內建範例檔案生成功能，透過系統分享匯出。

📱 如何安裝 Demo (Android)

前往本專案的 [Releases] 頁面。

下載最新的 app-release.apk 檔案。

安裝至 Android 手機即可開始使用。
