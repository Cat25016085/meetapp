# 🗳️ 會議簽到與投票系統 (Meeting Voting App)

這是一個專為會議管理設計的 Flutter 應用程式，具備完整的**身分權限管理**、**即時簽到儀表板**以及**動態投票系統**。

## ✨ 核心功能介紹

### 1. 👥 嚴謹的身分權限管理
系統將與會者分為以下四種身分：
- **主席 (Host)**：擁有最高權限，可發起投票、執行清點人數、結束投票。
- **紀錄 (Clerk)**：負責協助會議進行，擁有查看儀表板及控制公播畫面的權限。
- **出席 (Attendee)**：主要的投票者，需滿足特定條件才具備投票權。
- **列席/旁聽 (Observer)**：無投票權，僅能觀看會議進程。

### 2. ⚡ 獨特的「動態投票權」邏輯 (小明條款)
為了符合真實議事規則，本系統實作了嚴格的投票權檢核：
1. **簽到 ≠ 有票**：出席委員簽到後，狀態僅為「已簽到」。
2. **清點生效**：必須由主席或紀錄按下 **「執行清點人數」** 按鈕，當下已簽到的出席委員才會獲得「投票權」。
3. **遲到處理**：若委員遲到（在清點後才簽到），他暫時沒有投票權，需等待主席**再次執行清點**後，才能參與後續的投票案。

### 3. 📊 即時簽到儀表板
- **可視化統計**：即時顯示各身分類別的「已到/應到」人數。
- **詳細名單**：下方列表即時顯示每位與會者的簽到狀態與是否持有選票。

### 4. 🗳️ 動態投票系統
- **多案併行**：支援同時發起多個投票案，互不干擾。
- **靈活選項**：主席可動態新增/刪除投票選項 (不限數量)。
- **迴避原則**：發起投票時可指定「需迴避人員」，確保利益衝突者無法投票。
- **二次確認**：投票者在送出前需經二次確認，防止誤觸。
- **完整紀錄**：
    - **記名投票**：顯示每位投票者的選擇。
    - **不記名投票**：僅顯示票數。
- **精確棄權統計**：
    - 系統以「投票結束當下」的「具投票權總人數」作為分母。
    - 自動計算棄權數 (應投 - 實投) 與百分比。

### 5. 🌗 深色模式支援
- 支援一鍵切換深色/淺色模式，適應不同環境需求。

## 📱 操作指南 (User Guide)

### 第一步：建立會議 (由召集人操作)
1. 在首頁點選 **「建立會議」**。
2. 輸入會議名稱與主持人姓名。
3. **匯入人員名單**：
    - 點選「下載範例」取得 CSV 格式範例。
    - 依照 `學號,姓名,身分` 格式編輯 CSV 檔。
    - 點選「從 CSV 檔案匯入名單」。
4. 確認名單無誤後，點選「建立並進入」。

### 第二步：參加會議 (所有與會者)
1. 在首頁點選 **「參加會議」**。
2. 選擇目前正在進行的會議場次 (支援多場會議切換)。
3. 在人員列表中找到自己的名字並點選進入 (模擬身分驗證)。

### 第三步：會議進行中
1. **簽到**：進入會議室後，請點選上方的 **「點此簽到」** 按鈕 (列表上會即時顯示綠色勾勾)。
2. **取得權限**：等待主席宣布「清點人數」，此時若您已簽到，您將獲得投票權 (名單旁顯示藍色「有票」標籤)。
3. **投票**：
    - 當主席發起投票時，切換至 **「投票區」** 分頁。
    - 若您被列入該案「迴避名單」，系統將自動鎖定您的投票功能。
    - 選擇您的意向並點選確認 (需二次確認)。
    - **注意**：若為定時投票，時間到後將無法補投。

## 📂 檔案格式說明

若您要自行製作人員名單 CSV，請使用 UTF-8 編碼，內容格式如下：

```csv
學號,姓名,身分
A001,王大明,主席
A002,李小華,紀錄
B001,陳小明,出席
C001,張三,列席
```

> **注意**：身分欄位必須精確包含「主席」、「紀錄」、「出席」或「列席/旁聽」字眼，否則系統將預設為「出席」。
